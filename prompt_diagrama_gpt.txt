Create a clear architecture diagram of the following prototype.

The prototype is a single-hidden-layer Multilayer Perceptron (MLP) for tabular machine-learning problems. The hidden layer is trained with an Evolution Strategy using a Michigan-style representation. The central idea is:

"Instead of evolving a full neural network as one individual, this method evolves individual hidden neurons that cooperate to form the hidden layer."

In this prototype, each evolutionary individual represents exactly one hidden neuron. One individual is not a complete neural network. Each individual/neuron has:
- input weights;
- one bias;
- self-adaptive mutation parameters.

The population of neurons represents the hidden layer. During training, the algorithm starts with a parent population of hidden neurons. Offspring neurons are generated by mutation/self-adaptation. Parents and offspring are combined into a candidate pool. A neuron selection / credit-assignment mechanism chooses the surviving neurons. The selected neurons form the final hidden layer. Their activations on the input data form the hidden activation matrix Phi. A separate output layer is then fitted on this activation matrix.

The main output path is Ridge regression with Generalised Cross-Validation (GCV). Ridge + GCV fits the hidden-to-output weights analytically from the selected activation matrix. For binary classification it produces a real-valued score that is thresholded to obtain the predicted class. For regression it can output a continuous value.

There is also an optional alternative output path: logistic or softmax output trained with cross-entropy. This alternative uses the same selected hidden representation, but it does not use GCV. Do not make it as visually dominant as the Ridge + GCV path. Show it as a secondary optional branch.
