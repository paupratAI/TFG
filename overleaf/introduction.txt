\section{Introduction}
\label{sec:introduction}

\subsection{What the Project Studies}
\label{subsec:intro_what}

Neural networks are usually associated with gradient-based training. In most
modern applications, the parameters of a network are adjusted by
backpropagation: the loss is differentiated with respect to the weights and an
optimiser updates all parameters
jointly. This approach has been extraordinarily successful, and it is still the
standard choice in deep learning. It is not, however, the only way to train a
neural model. Evolutionary algorithms give a different view: instead of
following gradients, they search directly in a space of candidate solutions,
using variation and selection. The project studies that alternative in a
specific and controlled setting: a single-hidden-layer neural network for
tabular data.

The central idea of the thesis is to train the hidden representation of a
Multilayer Perceptron (MLP) with an Evolution Strategy (ES), but not in the
usual way of evolving a whole network as one individual. The implemented
prototype uses a Michigan-style representation. Each individual in the
evolutionary population is one hidden neuron: its input weights, its bias, and
its own mutation strategy. The complete hidden layer is formed by the surviving
population of neurons. Once this hidden representation has been selected, the
output layer is fitted separately with a model that matches the task. Binary
classification uses a logistic output trained with cross-entropy, regression
uses Ridge regression with Generalised Cross-Validation (GCV), and multiclass
classification uses a softmax output. In all cases, the hidden layer is not
updated by backpropagation.

This design was chosen because it separates two problems that are usually
solved together. The first problem is representation learning: finding a set of
nonlinear hidden neurons that transforms the input data into useful features.
The second problem is output fitting: combining those features to predict the
target. For regression, the second problem has a closed-form Ridge/GCV
solution once the hidden activations are fixed. For classification, the output
layer is fitted as a logistic or softmax model so that the predictions are
probabilities rather than least-squares scores. The evolutionary
search can then focus on discovering a useful hidden layer, while the final output
model remains simple and task-specific. This is conceptually different from a
conventional gradient-trained MLP, where all weights are adjusted together
through the same loss.

The representation is also different from the more common Pittsburgh-style
neuroevolution approach. In a Pittsburgh representation, each individual
encodes a complete model, so it is natural and easy to evaluate: one chromosome corresponds to
one candidate solution. The drawback is that every individual must be
evaluated as a full model. In the proposed Michigan formulation, the search is
performed at the level of individual hidden neurons. The evaluation
problem is less direct, because one neuron does not produce a prediction alone.
The main technical challenge is credit assignment: deciding which
neurons are useful and which are not.

The project began with the question of whether this neuron-level evolutionary
formulation could be useful in practice. More concretely, the thesis asks
whether a single-hidden-layer network whose neurons are evolved as individuals
can obtain competitive performance on tabular problems, whether it can do so
with a meaningful computational advantage over evolving whole hidden layers,
and whether the resulting architecture can be extended beyond the initial
binary classification setting.

\subsection{Motivation}
\label{subsec:intro_motivation}

The main motivation of this thesis is conceptual. The combination of
Evolution Strategies with a Michigan-style representation seems natural for a
single-hidden-layer neural network: an ES is well suited to continuous
parameters, and a hidden neuron is a small continuous object defined by its
weights and bias. If each individual represents one neuron, the evolutionary
population can be interpreted directly as the hidden layer. This idea is
simple, but it raises non-trivial questions about cooperation, credit
assignment, and computational cost. 

There is also a personal academic motivation. Before this thesis, I had
already worked with evolutionary algorithms, mainly genetic algorithms, in
previous coursework and projects. This gave me a basic background in
population-based search, mutation, selection, and fitness design. Continuing
to investigate evolutionary computation in a neural-network setting was
therefore a natural direction for the final-degree project. The aim was to
explore whether an evolutionary idea could be adapted into a coherent neural
architecture.

The Pittsburgh--Michigan distinction made the project especially interesting.
In a Pittsburgh approach, each individual is a complete model, so defining
fitness is intuitive: the model is evaluated and its performance becomes its
fitness. In the proposed Michigan approach, each individual is only one hidden
neuron. A neuron does not predict alone, so the method must decide which
neurons are useful because they cooperate well inside the final hidden layer.
This is the central design challenge of the thesis and the reason why the
selection strategy becomes as important as the mutation operator.

The project is also motivated by the possibility of a different
computational trade-off. Evolving complete networks can require many
high-dimensional model evaluations. Evolving individual neurons may allow the algorithm to
generate many small candidate features, select a cooperative subset, and fit
the output layer only after the hidden representation has been assembled. This
does not guarantee better performance, but it is a meaningful hypothesis to
test. The comparison with full-network Pittsburgh evolution is therefore one
of the most important parts of the experimental section, with a matched-budget
layer-level control used as an additional diagnostic.

\subsection{Objectives}
\label{subsec:intro_objectives}

The main objective of the thesis is to determine whether a Michigan-style
Evolution Strategy can be used to train the hidden layer of a compact neural
network for tabular problems, and whether this representation offers practical
advantages over evolving complete neural networks. This main objective is divided
into the following sub-objectives:

\begin{enumerate}
    \item To build a working prototype of a single-hidden-layer MLP in which
    each evolutionary individual represents one hidden neuron. The first
    requirement is not to obtain strong generalisation immediately, but to
    verify that the architecture can actually learn. For this reason, an early
    development objective is to make the prototype overfit controlled training
    splits, confirming that the evolved hidden neurons and the output layer have
    enough capacity to model the data.

    \item To define a coherent credit-assignment mechanism for the Michigan
    representation. In a Pittsburgh approach, assigning fitness is intuitive
    because each individual is a complete model. In this project, one individual
    is only one neuron, so the thesis must design a criterion that decides which
    neurons are useful for the final network. The objective is to select neurons
    that are not only individually related to the target, but also complementary
    when they form the hidden layer together.

    \item To establish a task-consistent output formulation once the hidden
    layer has been selected. Binary classification should use a probabilistic
    logistic output, regression should use the Ridge/GCV output where the
    closed-form solve is meaningful, and multiclass classification should use a
    softmax output. This objective is important because the output layer should
    match the prediction problem rather than force every task into the same
    formulation.

    \item To evaluate whether the evolved hidden representation adds measurable
    value in binary classification. This requires comparing the prototype not
    only with external tabular baselines, but also with internal ablations that remove
    the evolutionary hidden representation. The aim is to distinguish between
    the benefit of using a logistic output and the benefit of evolving useful
    nonlinear hidden neurons.

    \item To test whether the same design remains useful beyond binary
    classification. Once the binary version works correctly, the thesis studies
    two extensions: regression with Ridge/GCV and multiclass classification with
    softmax. The goal is not to claim that one architecture solves all tabular
    problems, but to check whether the Michigan hidden representation is
    flexible enough to support different output models.

    \item To compare the proposed Michigan representation against a
    Pittsburgh-style evolutionary representation. This
    is the objective most directly connected to the motivation of the project:
    if evolving individual neurons is worthwhile, it should offer some advantage
    in predictive performance, computational cost, generalisation behaviour, or
    accuracy-time trade-off when compared with evolving complete neural networks.
    A secondary objective is to include a matched-budget layer-level control to
    check whether the conclusion still holds when the output solver is shared.
\end{enumerate}

These objectives are intentionally empirical and architectural. The thesis does
not aim to prove a new convergence theorem or to show that the method dominates
all standard algorithms. The aim is to build a working prototype, understand the
design problems that appear when neurons are evolved as individuals, and assess
whether this Michigan-style neural architecture has practical value.

\subsection{Scope of the Thesis}
\label{subsec:intro_scope}

It is also useful to state what the thesis does not try to do. The project
does not attempt to build a large deep-learning system. It does not claim that
evolutionary algorithms should replace backpropagation for modern deep neural
networks. It also does not claim state-of-the-art performance on tabular
benchmarks. The scope is to implement a hybrid neural
architecture where the representation of the evolutionary population is the
main research variable.

This scope affects the way results are interpreted. If a classical baseline is
slightly better on a dataset, that does not automatically make the prototype
uninteresting. The relevant question is whether the proposed design behaves
coherently and whether it offers any measurable advantage in the situations it
was designed for. For example, the logistic binary architecture is valuable
because it evaluates the evolved representation with a proper probabilistic
classifier. The Ridge/GCV regression architecture is valuable because it keeps
the output layer analytically solvable. The softmax variant is valuable
because it shows how the evolved hidden representation can be used in a
probabilistic multiclass model. The sparse logistic experiment is valuable
because it shows that the final hidden layer can be compressed after
evolutionary selection. The Michigan--Pittsburgh experiment is valuable
because it tests the initial representation hypothesis directly, first against
full-network Pittsburgh evolution and then with a matched-budget layer-level
control.

The thesis follows an engineering research style. It starts from a
conceptual idea, implements it, identifies its weaknesses, improves the
experimental protocol, and compares the final method against relevant
alternatives. Negative and mixed results are kept in the discussion because
they help define what the method can and cannot support.
