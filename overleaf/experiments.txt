\section{Experiments}
\label{sec:experiments}

The experimental evaluation is not organised as a single leaderboard. Each
experiment answers a different question about
the proposed architecture. The binary classification experiments use the
logistic output architecture, because it is the natural probabilistic
formulation for two classes. The regression experiments use the Ridge/GCV
architecture, because Ridge is naturally a regression model and preserves the
closed-form output solve. Later experiments test sparsity, multiclass softmax,
and finally the Michigan--Pittsburgh comparison.

\subsection{Experimental Setting}
\label{subsec:experiments_setting}

The binary classification experiments use three OpenML datasets:
Breast-W, Ionosphere, and Sonar. OpenML provides a common platform for sharing
datasets and machine-learning experiments~\cite{vanschoren2013openml}. The
three selected datasets are small tabular datasets often used as classical
binary benchmarks. They also provide a useful mix for this thesis: Breast-W is
comparatively low-dimensional and close to linearly separable, Ionosphere is a
moderate-dimensional signal dataset with more nonlinear structure, and Sonar is
small and higher-dimensional, which makes overfitting easier. This combination
is appropriate for testing whether the selected hidden neurons add value beyond
a simple linear classifier. Each dataset is processed with stratified
train/validation/test splits, median imputation, and standardisation fitted
only on the training split. For the logistic experiments, the labels are
mapped to $\{0,1\}$.

Unless a specific experiment states otherwise, the binary ES configuration
uses 50 hidden neurons and 250 offspring neurons per generation. The selected
checkpoint is the generation with the highest
validation accuracy, with validation cross-entropy as tie-breaker. Test metrics are
computed only after this selection. The test set is
intended to simulate unseen data.

The following metrics are reported:

\begin{itemize}
    \item validation and test accuracy for classification;
    \item test ROC-AUC for score ranking;
    \item cross-entropy, Brier score, and ECE for probabilistic binary and
    multiclass classification;
    \item fit time for computational comparison;
    \item RMSE, MAE, and $R^2$ for regression.
\end{itemize}

The evaluation is organised around seven groups of experiments: comparison of
neuron-selection strategies, binary classification against tabular baselines,
architectural ablations, regression benchmarks, sparse output filtering,
multiclass softmax classification, and the final Michigan--Pittsburgh
comparison. The figures and tables reported in this section are generated
from the saved experimental summaries.

\subsubsection{Reproducibility protocol.}

The experimental protocol follows three principles. First, preprocessing must
not leak information from validation or test data. This is handled by fitting
imputers and scalers only on the training split. Second, model selection must
use validation data, not test data. This applies to checkpoint selection,
random-feature hidden width, L1-logistic sparsity strength, and regression
strategy selection. Third, final reported test metrics must come from the
selected model, not from manually choosing the best test result.

The experimental workflow saves structured summaries for each benchmark, and
the figures used in this report are generated from those summaries. This is
useful because it separates execution from writing and makes it possible to
check the raw rows and configurations behind each table.


\subsubsection{How to read the results.}

The tables report means and variability across the runs available for each
experiment. In the strategy and binary classification benchmarks, the values
are mean $\pm$ standard deviation over datasets and seeds. In the
Michigan--Pittsburgh comparison, values are mean $\pm$ standard error over
the 15 dataset/seed runs. The L1-logistic sparsity experiment uses ten seeds and also
reports the number of active neurons.

Validation and test accuracy have different roles. Validation accuracy is used
for selection: checkpoint selection, strategy selection in some settings, and
hyperparameter choices such as random hidden width or L1 sparsity strength. Test
accuracy is used for final evaluation. A model with higher validation accuracy
but lower test accuracy is not automatically better; it may be overfitting the
validation split. The Michigan--Pittsburgh experiment therefore reports the
validation-test gap explicitly.

ROC-AUC is included because logistic and softmax outputs produce continuous
probabilities or scores that can be ranked. Cross-entropy and Brier score
measure probability quality, while ECE gives a simple calibration diagnostic.
Runtime is reported as fitting time, but its interpretation differs between
classical baselines and the evolutionary prototype. For that reason, the most
meaningful runtime result is the Michigan--Pittsburgh experiment, where both
methods are evolutionary neural models and share the same output solver.

\subsection{Results and Discussion}
\label{subsec:experiments_results_discussion}

\subsubsection{Neuron-Selection Strategy Comparison}
\label{subsec:experiments_strategy}

The first experiment compares the strategies used to select hidden neurons
inside the Michigan population. This is a necessary experiment because the
representation creates a credit-assignment problem. A neuron is not a complete
model, so the algorithm needs a criterion to decide which neurons should
survive.

The compared strategies are OMP, marginal $R^2$ with diversity penalty, CFS,
and CFS-AUC. OMP greedily selects neurons according to residual information.
$R^2$ rewards individual neuron-target correlation and penalises redundancy.
CFS rewards relevance to the target and penalises redundancy within the
selected subset. CFS-AUC uses univariate AUC for relevance and Spearman
correlation for redundancy.

The experiment was run on Breast-W, Ionosphere, and Sonar with three seeds
($42$, $43$, and $44$), 60 generations, 50 surviving neurons, 250 offspring,
and a validation split. Table~\ref{tab:strategy_overall} reports the aggregate
result.

CFS is the strongest overall strategy in this experiment. It obtains the
highest validation accuracy, test accuracy, ROC-AUC, and the best Brier/ECE
among the compared strategies. This justifies using ES-CFS Logistic CE as the
main binary classification prototype in later experiments. The result also
shows why several metrics are needed. OMP has the lowest mean cross-entropy,
but CFS gives the best overall classification and ranking behaviour.

CFS-AUC is conceptually attractive because its relevance term is directly
related to binary classification ranking. However, it does not beat CFS
overall in these experiments and it is more expensive. The conclusion is that
CFS is the most useful default strategy for the current logistic architecture,
while CFS-AUC remains an interesting but not clearly superior variant.

The cost comparison strengthens this interpretation. Marginal $R^2$ is the
cheapest selection rule, with a mean selection cost of about $0.513$ ms per
generation. OMP and CFS are still inexpensive, at about $1.012$ ms and
$1.234$ ms respectively. CFS-AUC is very different: its ranking and Spearman
correlation computations increase the mean selection cost to about $45.000$ ms
per generation, and the mean total training time rises from below one second
for the other strategies to about $3.194$ s. CFS-AUC would therefore need a
clear predictive gain to justify its cost, which is not observed in this
experiment.

The per-dataset results give more nuance. Table~\ref{tab:strategy_per_dataset}
shows that CFS is especially strong on Ionosphere and Sonar, while CFS-AUC is
very strong on Breast-W. This is consistent with the nature of the
selection criteria. CFS-AUC directly rewards ranking quality, which works well
when individual neurons can separate the classes reliably. CFS is more
balanced when redundancy between neurons becomes important.

The table also shows why it would be misleading to report only one metric.
On Breast-W, OMP has the highest test accuracy and AUC, while $R^2$ has the
highest validation accuracy. On Ionosphere, CFS and $R^2$ tie in mean test
accuracy, but CFS has much stronger AUC. On Sonar, OMP is strongest in test
accuracy and cross-entropy, while CFS-AUC has the highest validation accuracy.
For that reason, later experiments use validation for selection but interpret
test accuracy, AUC, probability metrics, and runtime together.

From an architectural point of view, the result favours subset-level credit
assignment over purely marginal scoring. The $R^2$ strategy is simple and
fast, but it mostly asks whether one neuron is individually correlated with
the target. This is not enough when the final hidden layer is a cooperative
set. OMP and CFS are closer to the real problem because they consider the
relationship between selected neurons. OMP does this through the residual,
while CFS does it through explicit redundancy penalties. In these datasets,
CFS gives the best balance.

The experiment also shows that a more classification-specific criterion is
not automatically better. CFS-AUC was introduced because AUC is a natural
ranking metric for binary classification and Spearman correlation can detect
monotonic redundancy. This is theoretically reasonable, but the empirical
result is mixed. One possible explanation is that univariate AUC is useful for
ranking individual neurons, but the final logistic model combines neurons
jointly. A neuron that is not the best univariate ranker can still be useful
when it complements other selected neurons. Another explanation is cost:
ranking every candidate activation introduces extra computation, and the
improvement is not consistent enough to justify it as the default strategy.

\subsubsection{Comparison with Standard Tabular Baselines}
\label{subsec:experiments_baselines}

The second experiment asks whether the proposed ES-CFS Logistic CE model is
competitive against standard tabular methods. The comparison includes:

\begin{itemize}
    \item RBF SVM, a strong nonlinear kernel classifier;
    \item Random Forest;
    \item HistGradientBoosting;
    \item Logistic Regression;
    \item Linear Logistic CE;
    \item Random tanh Logistic CE;
    \item Gradient MLP;
    \item ES-CFS Logistic CE, the proposed binary classification model.
\end{itemize}

This experiment is important because the prototype should not be evaluated
only against weak or artificial baselines. The results are shown in
Table~\ref{tab:defence_baselines} and
Figure~\ref{fig:binary_benchmark_summary}.

The strongest model in mean test accuracy is RBF SVM, with $0.918$. The
logistic ES prototype obtains $0.881$. This is below the best classical
baselines, but it improves over both Linear Logistic CE and Random tanh
Logistic CE. It also obtains the best mean validation accuracy in the table.
This suggests that the evolved representation is useful, although the final
test comparison remains mixed because the classical tabular baselines are
very strong on these datasets.

The conclusion must be balanced. ES-CFS Logistic CE is not universally better
than standard tabular methods. It is slower than several classical baselines in
this small benchmark, and RBF SVM has the highest average test accuracy.
However, the prototype is stronger than the logistic ablations and keeps the
classification output probabilistic. This supports the idea that the evolved
hidden representation has value, even if the binary logistic architecture is
not the strongest practical classifier in this benchmark.

The dataset-level behaviour also matters. On Breast-W, most models perform
very well, which suggests that the problem is relatively easy after
preprocessing. On Ionosphere and Sonar, the evolved representation gives a
clearer advantage over its own linear and random-feature logistic ablations
than over the strongest external baselines. These observations are not enough
for a universal claim, but they show that the method is not only exploiting
one special dataset.

The comparison also helps identify the real role of the prototype. It is not
the fastest model in the table, and it does not beat the RBF SVM in mean test
accuracy. However, it is stronger than the gradient MLP baseline under the
tested settings and clearly better than random tanh logistic features. This is
important because small tabular datasets are often difficult for standard
neural networks. The result suggests that the proposed training decomposition
can make a compact neural model meaningful in a setting where a conventional
MLP is not automatically strong.

It is also worth noting that the external baselines are not designed to answer
the Michigan question. They answer a practical modelling question: whether the
prototype is reasonable compared with known tabular methods. The answer is
yes, but with limits. The deeper architectural evidence comes from the
ablation and from the Michigan--Pittsburgh comparison, because those
experiments isolate the effect of the evolved representation.

The ranking panel adds useful context without changing the conclusion. ES-CFS
Logistic CE is not the top-ranked model overall, but it ranks above Random
tanh Logistic CE and Gradient MLP. This reinforces the interpretation that
the evolved hidden representation adds value, while the external tabular
baselines remain very strong competitors.

\subsubsection{Ablation of the Binary Logistic Architecture}
\label{subsec:experiments_ablation}

The next experiment isolates the value of the evolved hidden representation.
It compares three logistic models:

\begin{itemize}
    \item Linear Logistic CE, which uses the original input features directly;
    \item Random tanh Logistic CE, which uses randomly generated tanh hidden
    features;
    \item ES-CFS Logistic CE, which uses the evolved hidden representation.
\end{itemize}

This ablation answers a central question: is the gain caused simply by using a
logistic output, by adding nonlinear features, or by evolving/selecting useful
nonlinear features?

\begin{figure}[htbp]

This is one of the clearest binary-classification results. Linear Logistic CE
is a simple baseline, and Random tanh Logistic CE tests whether arbitrary
nonlinear features are enough. The evolved ES-CFS representation obtains the
best validation accuracy, test accuracy, and ROC-AUC among the three logistic
variants.

The gain is therefore not simply due to adding a hidden layer or using
nonlinear random features. The evolutionary selection of hidden neurons is
doing useful work.

This ablation is essential because it separates the output formulation from
the representation. Linear Logistic CE uses the same type of probabilistic
output layer, but without a hidden representation. Random tanh Logistic CE
uses a nonlinear hidden layer, but without evolutionary search. ES-CFS
Logistic CE is the only model that combines both the nonlinear representation
and the Michigan selection process.

The fact that random tanh features do not improve over linear logistic output
on average is also informative. It means that adding nonlinear capacity is not
free. Random hidden neurons can create noisy or redundant features, and the
unregularised logistic output may become overconfident. The ES selection step
acts as a learned feature generator: it searches for nonlinear transformations
that are more aligned with the target and more useful as a set.

Because the output layer is logistic, the model also produces probabilities.
That is why probability metrics are reported in the strategy and benchmark
tables, not only accuracy and ROC-AUC. The main caution is that ES-CFS Logistic
CE improves the hard classification metrics among the logistic variants, but it
does not always minimise cross-entropy. This is consistent with some splits
becoming close to linearly separable in the selected hidden representation,
which can drive an unregularised logistic output towards very confident
probabilities. This observation motivates the later sparse logistic experiment.

\subsubsection{Regression-Oriented Ridge Benchmark}
\label{subsec:experiments_regression}

Because Ridge/GCV is the regression-oriented output layer of the prototype,
it is natural to ask whether the evolved representation also has value for
continuous prediction. The regression benchmark adapts the same idea: evolve
the tanh hidden representation, then fit the output layer analytically with
Ridge/GCV. The checkpoint is selected by validation RMSE.

The experiment uses three datasets:

\begin{itemize}
    \item CaliforniaHousing-12000, a real housing-value regression dataset
    with a continuous target;
    \item Friedman1-12000, a synthetic continuous regression dataset;
    \item Diabetes, a real continuous regression dataset from scikit-learn.
\end{itemize}

California Housing is appropriate here because its target is genuinely
continuous: the median house value of a district. This makes it a natural
benchmark for the Ridge/GCV regression path. It is also useful because it is a
real tabular problem with nonlinear effects and only eight input features, so
the experiment tests whether the evolved tanh representation can add value
beyond a linear Ridge model in a genuine regression setting.

The compared models are Linear Ridge+GCV, Random tanh Ridge+GCV, ES-selected
Ridge+GCV, HistGradientBoosting, and Gradient MLP. For the ES model, CFS, OMP,
and $R^2$ are evaluated on validation data, and the strategy with the lowest
validation RMSE is reported.

measurable value to the closed-form Ridge output model, and the same idea can
be extended beyond classification.

The value summary focuses on the most relevant regression question: whether
the evolved representation improves the Ridge output model. It does so on all
three continuous regression datasets. The improvement is especially visible on
CaliforniaHousing-12000 and Friedman1, where the nonlinear structure of the
data makes the linear Ridge baseline clearly insufficient. At the same time,
the comparison with HistGradientBoosting shows that specialised tabular
regressors can still be better on some problems.

The best selection strategy changes by dataset: OMP for CaliforniaHousing-12000
and Friedman1, and $R^2$ for Diabetes. This confirms that neuron selection is
a real modelling choice. It also supports validation-based strategy selection:
in the three regression datasets, the best validation strategy also obtains
the best test RMSE among the ES candidates.

The regression experiment also helps interpret the role of CFS. In binary
classification, CFS is the strongest overall strategy. In regression, CFS is
not always best. This is not a contradiction. The strategies use different
signals, and different target structures may reward different forms of credit
assignment. CaliforniaHousing-12000 and Friedman1 both reward OMP's residual
criterion in the reported run, while Diabetes is a small real regression
dataset where marginal $R^2$ with diversity is best.
This suggests that future versions of the method should not hard-code a single
selection rule for every task.

Overall, the regression results strengthen the thesis in a specific way. They
do not show that the prototype is a universal replacement for tree ensembles.
They show that the evolved tanh representation is useful when the output
layer is a Ridge regressor and the target is continuous. This matters because
the Ridge/GCV regression architecture is naturally
compatible with regression. In this experiment the output layer is used
exactly as a regression model, not as a classifier. The fact that the
ES-selected representation improves over linear and random-feature Ridge in
this setting makes the representation argument more robust.

\subsubsection{L1-Logistic Output-Layer Filtering}
\label{subsec:experiments_lasso}

The ES-CFS model always starts from the same hidden representation: the
Michigan ES selects 50 hidden neurons from the candidate pool. The question in
this experiment is what should happen after those 50 neurons have been
selected. The standard logistic output uses the complete selected hidden
layer. However, the fitness strategy used during evolution is still a
cooperative criterion, so it is possible that some surviving neurons are useful
for the selection process but redundant once the final logistic output is
fitted. The L1-logistic experiment therefore tests whether the output layer can
act as a second, simpler filter by setting unnecessary output coefficients
exactly to zero.

Three variants are compared, and they differ only in the output layer fitted
after ES-CFS has selected the hidden representation. \emph{Full ES-CFS
Logistic CE} is the reference model: it fits an unregularised logistic output
with cross-entropy using all 50 ES-selected neurons, so no neuron is removed
after the evolutionary stage. \emph{ES-CFS L1 Logistic} fits a sparse logistic
output on the same 50 neurons. In this case, the L1 penalty is part of the
final classifier itself: neurons whose output coefficient is driven to zero do
not contribute to the prediction, and the remaining coefficients are the
regularised coefficients used at test time. \emph{L1-screened ES-CFS Logistic
CE} is a two-stage variant. First, an L1-logistic model is used only to screen
the hidden layer and identify the neurons with non-zero coefficients. Then the
zero-weight neurons are discarded, and a new unregularised logistic output is
refitted with cross-entropy on the reduced hidden layer. Thus, ``screened''
means that L1 is used as a neuron-selection filter, not as the final set of
output weights.

The experiment uses Breast-W, Ionosphere, and Sonar with ten seeds. The L1
regularisation strength is selected on the validation split using a
sparsity-aware rule:
\[
    \mathrm{ValAcc}
    -
    0.05
    \frac{\#\mathrm{active\ neurons}}{50}.
\]
The test set is not used for selecting the L1 parameter. This makes the
comparison useful for two questions at once: whether the 50-neuron hidden
layer can be compressed, and whether removing neurons improves or damages
final predictive performance.

\subsubsection{Michigan vs. Pittsburgh Representation}
\label{subsec:experiments_michigan_pittsburgh}

The final experiment is the most directly connected to the original motivation
of the thesis. It compares the proposed Michigan representation with a
Pittsburgh-style evolutionary representation. In this thesis, Pittsburgh is
understood in its usual neuroevolution sense: one individual represents a
complete neural network. For the binary task used here, a Pittsburgh
individual encodes the input-to-hidden weights, hidden biases,
hidden-to-output weights, and output bias of a one-hidden-layer logistic
network. The individual is evaluated directly as a complete model.

This comparison is intentionally demanding for the proposed method. Michigan
does not evolve a full network. It evolves hidden neurons, selects a
cooperative hidden layer, and then fits the output model separately. Pittsburgh
evolves all network parameters at once. The question is therefore whether the
separation between hidden-representation search and output fitting gives a
better accuracy-time trade-off than evolving complete networks directly.

Both architectures use the same datasets, splits, preprocessing, tanh hidden
activation, final hidden width, and validation-based checkpoint selection. The
main difference is what one evolutionary individual represents:

\begin{itemize}
    \item Michigan ES-CFS: each individual is one hidden neuron. The population
    forms the hidden layer. The method creates 250 new candidate neurons per
    generation and fits the logistic output once per generation.

    \item Pittsburgh ES: each individual is a complete one-hidden-layer
    network, including the output weights. The method evaluates 400 complete
    networks per generation and does not fit a separate output layer after
    decoding an individual.
\end{itemize}

The experiment was run on Breast-W, Ionosphere, and Sonar with five seeds
($42$--$46$), 50 generations, and 50 hidden neurons.

accurate on test data and substantially cheaper to train.

This does not prove that every Michigan method is better than every Pittsburgh
method. The datasets are small binary tabular datasets, and a different

does address the central question of the thesis directly: when Pittsburgh is
implemented as full-network evolution, the proposed Michigan representation
offers a better generalisation-cost balance in the tested setting.

\subsubsection{Matched-Budget Pittsburgh Variant}
The full-network comparison is conceptually the most faithful Pittsburgh
baseline, but it changes the output training mechanism: Pittsburgh evolves the
output weights, while Michigan fits them after selecting the hidden layer. For
that reason, a secondary Pittsburgh variant was also included. This variant is
not the main Pittsburgh baseline used in the thesis, because its individual
does not contain the output weights. Instead, each Pittsburgh individual
represents a complete hidden layer of 50 neurons. Once this hidden layer is
decoded, it is evaluated with the same logistic output fitting procedure used
by Michigan. The purpose of this variant is to keep the output solver fixed
and isolate the representation question: Michigan evolves individual neurons
that later cooperate, whereas this Pittsburgh variant evolves complete hidden
layers as indivisible candidates.

The control is matched by the number of newly generated hidden neurons.
Michigan creates 250 new candidate neurons per generation. The matched-budget
Pittsburgh variant uses 5 parent hidden layers and 5 offspring hidden layers;
since each layer has 50 neurons, it also creates 250 new hidden neurons per
generation. The difference is that this Pittsburgh variant must fit the
logistic output for 10 complete hidden layers per generation, whereas Michigan
fits it once after selecting its neuron population.

\subsubsection{Wilcoxon Paired Signed-Rank Test}
\label{subsubsec:exp_wilcoxon_michigan_pittsburgh}

The descriptive averages above are useful, but they do not by themselves show
whether the observed differences are consistently aligned across individual
runs. For that reason, a Wilcoxon paired signed-rank test was added to the
final comparison~\cite{wilcoxon1945}. This test is appropriate here because
the observations are naturally paired by dataset and random seed, the number
of runs is limited, and the test does not require assuming that the paired
differences are normally distributed.

Two paired comparisons are analysed. The first compares Michigan ES-CFS with
the full Pittsburgh ES baseline, where one Pittsburgh individual is a complete
neural network. The second compares Michigan ES-CFS with the matched-budget
Pittsburgh variant, where one Pittsburgh individual is a complete hidden
layer evaluated with the same logistic output solver used by Michigan. In both
cases, each pair corresponds to the same dataset, seed, split, and test
metric. The paired difference is defined as
\[
    \Delta =
    \mathrm{metric}_{\mathrm{Michigan}}
    -
    \mathrm{metric}_{\mathrm{Pittsburgh}},
\]
so positive values favour Michigan and negative values favour Pittsburgh. Test
accuracy is the primary metric. Test ROC-AUC is included as a secondary
analysis because individual paired ROC-AUC values are available for all
architectures. The tests are bilateral, use $\alpha=0.05$, and the secondary
ROC-AUC p-values are adjusted with Holm--Bonferroni correction. Zero
differences, when present, are discarded from the signed-rank calculation
using the standard Wilcoxon convention. The implementation uses the automatic
SciPy method, which applies an exact calculation when it is valid and otherwise
uses the appropriate fallback for ties or zero differences.

\centering

Observations are paired by dataset and seed, $\Delta$ is computed as Michigan minus Pittsburgh, all metrics are test metrics, and the test is bilateral. Adjusted p-values are Holm--Bonferroni corrected only for the secondary ROC-AUC analyses.}
\label{tab:wilcoxon_michigan_pittsburgh}
\resizebox{\textwidth}{!}{%
\begin{tabular}{llrrrrrrl}

Comparison & Metric & $n$ & Median $\Delta$ & $W$ & p-value & Adjusted p-value & Rank-biserial effect & Interpretation \\
\midrule

Michigan vs. Pittsburgh ES & Test ROC-AUC & 15 & $0.095$ & $15.000$ & $0.008$ & $0.008$ & $0.750$ & Significant, favours Michigan \\
Michigan vs. Pittsburgh matched-budget & Test accuracy & 15 & $0.056$ & $2.000$ & $0.002$ & -- & $0.962$ & Significant, favours Michigan \\

The primary test-accuracy results reject the null hypothesis of zero median
paired difference in both comparisons. Against full Pittsburgh ES, the median
paired test-accuracy difference is $0.042$ in favour of Michigan, with
$p=0.002$ and a positive rank-biserial effect of $0.892$. Against the
matched-budget Pittsburgh variant, the median paired difference is $0.056$,
also in favour of Michigan, with $p=0.002$ and a rank-biserial effect of
$0.962$. These results indicate that the mean differences reported earlier
are not driven only by a small number of favourable runs.

The secondary ROC-AUC analysis points in the same direction. After
Holm--Bonferroni correction, both ROC-AUC comparisons remain significant:
$p=0.008$ for Michigan against full Pittsburgh ES and adjusted $p<0.001$ for
Michigan against the matched-budget Pittsburgh variant. This supports the
interpretation that the advantage is not limited to hard accuracy, but also
appears in the ranking quality of the probabilistic scores. Training time is
kept as a separate efficiency argument: the statistical test evaluates
predictive test metrics, while the runtime results above describe the
accuracy-time trade-off.

The paired statistical analysis complements the descriptive averages reported
above. Rather than relying only on mean test performance, it evaluates whether
the observed differences are consistently aligned across matched runs. Under
the experimental conditions considered here, the result supports the claim
that the Michigan representation offers a better generalisation profile than
the Pittsburgh baseline. This conclusion is limited to the evaluated datasets,
seeds, computational budget, and implementation choices, and should not be
interpreted as a universal superiority claim over all forms of neuroevolution.

\subsubsection{Overall Experimental Discussion}
\label{subsec:experiments_overall}

The experiments support the thesis in several complementary ways. The
selection-strategy comparison shows that credit assignment matters. The
baseline benchmark and the logistic ablation show that the evolved hidden
representation adds value beyond linear and random-feature logistic models,
even though classical tabular baselines remain very strong. The regression
benchmark keeps the Ridge/GCV architecture where it is most natural, while
the L1-logistic and softmax experiments broaden the probabilistic
classification evidence. The full-network Michigan--Pittsburgh comparison,
supported by the matched-budget Pittsburgh variant, addresses the original
motivation directly.

The most specific evidence comes from the logistic ablation, the regression
Ridge ablation, and the Michigan--Pittsburgh comparison. The ablations isolate
the value of evolving the hidden representation; the final comparison
tests the value of using a Michigan representation instead of full-network
evolution. The extension experiments add breadth, but they are
not treated as universal proof of superiority.

\subsubsection{Threats to Validity}
\label{subsec:experiments_threats}

The main threats to validity are dataset scale, seed sensitivity, and the
limited scope of the Pittsburgh baseline. The binary experiments use only
three small tabular datasets, and several experiments would benefit from more
seeds. The Pittsburgh comparison uses one concrete full-network ES baseline,
not every possible Pittsburgh neuroevolution method. The matched-budget
Pittsburgh variant is useful for isolating representation, but it should be
interpreted as an auxiliary diagnostic rather than as the default Pittsburgh
formulation.

Another limitation is that the ES hyperparameters were chosen for a practical
prototype rather than exhaustively optimised. The logistic and
softmax classifiers should not be merged with the Ridge/GCV regression
results into a single claim: they represent related but different output-layer
formulations. These limitations bound the conclusions, but they do not remove
the main result that the Michigan-style representation is coherent and
favourable in the comparisons tested here.
